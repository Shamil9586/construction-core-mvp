# Доступ

Авторитетная матрица — Permission enum и grants в `packages/domain/index.ts`. Все mutations проверяют backend permission до изменения БД.

| Роль | Возможности |
|---|---|
| ADMIN | Все операции, справочники, пользователи, импорт, настройки |
| GENERAL_DIRECTOR | Просмотр объектов, производства, ИД, СДО, финансов и аудита |
| DEPUTY_DIRECTOR | Канонический текущий управленческий роль (F12.3, «Заместитель директора»): просмотр обоих контуров (строительного и технического), создание/редактирование объектов и работ, переназначение РП, аудит — единственная текущая управленческая роль (ROLE-CLEANUP: прежние роли TECHNICAL_DIRECTOR и DEPARTMENT_HEAD удалены, хранимые строки мигрированы в DEPUTY_DIRECTOR; текущие начальники подразделений — только PTO_HEAD / CONSTRUCTION_CONTROL_HEAD / SDO_HEAD). Не выполняет операционные действия ПТО/СДО/СК (нет DOCUMENTATION_MANAGE, SDO_CASE_MANAGE, INSPECTION_ACCEPT/REJECT) |
| PROJECT_MANAGER | Собственные объекты, работы, факт, предъявление СК, устранение замечаний |
| CONSTRUCTION_CONTROL | Замечания, фото, проверка устранения, приёмка/отклонение |
| PTO | Материалы, ИД, подготовка и передача комплекта |
| SDO | Ввод расчёта, финансовое закрытие |
| CONTRACTOR_VIEWER | Связанные объекты и свои работы; без финансов |

GPR-2 (R01): права новых функций (`/v2`, ГПР-2, объёмы, внешняя пригодность, публикация) живут отдельно — `packages/domain/gpr2/permissions.ts` (явная таблица для каждой роли, ADMIN получает только публикацию справочников, N01 — по умолчанию никому). Они намеренно не входят в `Permission`, чтобы `Object.values(Permission)` у ADMIN не выдавал их автоматически. Подробности: `docs/gpr-2-r01-contracts.md`.

Проект не считает email внешним ключом; используется bitrixUserId внутри tenant. Установка создаёт только заранее настроенного ADMIN. Остальных назначает администратор приложения. Автоматического повышения роли из входящего payload нет. Для production понадобятся детальные ограничения руководителей по подразделениям и периодический отзыв доступа у деактивированных сотрудников Bitrix.
