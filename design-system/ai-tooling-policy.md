# AI tooling preparation policy (policy only — nothing installed or run)

Precedence (from `.claude/ui-skills-governance.md`): accepted Product/UX architecture → domain terminology → this design system → repo conventions → Impeccable → design-taste-frontend.
No tool below may change domain semantics, API contracts, roles/permissions, workflows, or navigation architecture.

## DESIGN.MD
- Status: **not generated.** `/impeccable init` has not been run; generating `DESIGN.md` is a deliberate human decision.
- When approved: derive it **from the shipped design system and these docs**, not from aesthetic preference; it must restate the locked principles,
  status vocabulary, token layers and forbidden patterns verbatim-in-spirit; sidecar generated from the shipped artifact.
- Review: product owner + design owner sign off before it is used as AI context.

## UI Rules Audit
- A checklist-driven review (manual or AI-assisted) of a change against `forbidden-patterns.md`, `component-rules.md`, `accessibility-rules.md`, `visual-consistency-rules.md`.
- Output: table of rule id → pass/fail/NA with file:line. Any F1–F18 hit blocks.
- Advisory only; findings that conflict with accepted UX are rejected, not "fixed".
- Run per frontend PR before Playwright gate; record result in PR description.

## Playwright UI Gate
- Proposed gate (not executed in F13.1): existing `npm run test:ds` (isolated preview, no backend) must stay green; screen specs extended per state in `frontend-handoff.md`.
- Assertions to add for implementation phases: no `<small>`; badges have text; progress bar has name/value or is decorative; C01 has no ИД/СК/finance text; O01 has no SC/ИД/finance; W01 shows three distinct confirmation items; history has no edit controls; axe-style contrast/keyboard checks at 1440 and 390 px.
- Product suite (`npm run test:browser`) failures are separate and recorded in `docs/status.md`; they are neither cleared nor hidden by this gate.
- Visual snapshot tests only after baseline approval, with stable fonts/locale/timezone.

## 21st.dev
- Status: **not installed, not used.** No dependency added.
- Policy if adopted later: treated as inspiration/reference only. Generated components are **never** pasted into production: they must be rebuilt on tokens,
  pass UI Rules Audit and the Playwright gate, carry no external styling dependency, and have license reviewed. Adoption requires an architecture review (new dependency).
- Forbidden: components that bring their own palette, shadows, motion, or data semantics; any component that infers business state from colour.

## General
- No production components generated by AI in F13.1. Any AI-authored change goes through normal review and the gates above.
- No secrets, customer data or real object data in prompts.
