# ADR-0001. Производственное ядро вне Bitrix24

Статус: принято. 14.09.2026.

Bitrix24 служит оболочкой. React 19 + TypeScript + Vite + Router + TanStack Query + Ant Design образуют frontend. NestJS обслуживает REST API. PostgreSQL хранит нормализованные данные. Domain-сервисы не импортируют React, NestJS, pg или Bitrix.

Для этой реализации используется node-postgres с параметризованными запросами, SQL-миграциями и выделенным слоем repository helpers вместо Prisma. Это отступление от предпочтительного ORM: SQL явно задаёт составные tenant-FK, частичные уникальные индексы и неизменяемый аудит. Динамические значения всегда передаются параметрами. Смена слоя persistence не меняет расчёты domain.

PGlite используется только для локального тестирования в ограниченной среде. Это PostgreSQL в WASM, а не проверенный сетевой процесс PostgreSQL. Docker Compose нацелен на PostgreSQL 17. Production и реальный портал не затрагивались.

Локальное серверное приложение с UI в iframe — базовая интеграция. CRM, сделки, смарт-процессы и пользовательские поля не являются базой строительных данных. Приложение не меняет ядро Bitrix24.
